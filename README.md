# 机器人与工程知识库

按知识主题组织机器人、软件、电子与学习笔记。每个模块先介绍范围、前置知识和阅读顺序，再进入具体文章。公式中的坐标系、单位与假设以文章中的定义为准；教学示例中的数值不代表设备的推荐配置。

初学机器人可按“数学 → 坐标变换 → 传感器 → ROS → 点云与定位 → 导航与控制”阅读；学习视觉算法可从图像处理、数据与评测入手，再结合性能分析。软件、界面与电路模块也可独立阅读。

每个知识点由一篇文章主讲，其他模块通过链接引用。修改时直接更新对应文章和模块导航；新增内容应说明适用条件，并在文章末尾保留支持关键结论的公开资料。ROS 1、ROS 2 及其他技术的版本差异在相关正文中说明。

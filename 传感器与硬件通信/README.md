# 传感器与硬件通信

本模块讲传感器怎样把物理量变成数字测量，测量值怎样获得单位、时间和坐标语义，以及驱动如何通过串行链路、CAN 和 EtherCAT 把数据交给机器人软件。重点是协议边界、数据质量、时钟和资源生命周期。

## 前置知识

- 会读基本的 C++ 或 Python，理解字节、整数、有符号数、线程和文件描述符。
- 熟悉向量、矩阵和基本信号处理；复习见[数学与信号基础](../数学与信号基础/README.md)。
- 会使用 Linux 终端，并了解传感器、控制器、执行器和总线的基本角色。

## 建议阅读顺序

1. [传感器测量与时间戳](传感器测量与时间戳.md)：读懂编码器、IMU、深度与测距传感器的测量边界，区分采样时刻和接收时刻。
2. [串行协议与有界解析](串行协议与有界解析.md)：从分块字节流构造安全、有界、可重同步的帧解析器。
3. [CAN 与 SocketCAN](CAN与SocketCAN.md)：理解 CAN 仲裁标识符、错误状态和 Linux 用户态接口。
4. [EtherCAT 通信](EtherCAT通信.md)：理解周期过程数据、对象字典、工作计数器与分布式时钟。
5. [驱动数据流、消息与生命周期](驱动数据流、消息与生命周期.md)：将 SDK、驱动线程、缓冲、ROS 消息和设备身份接成完整数据链。

## 范围与约定

传感器帧、通信帧、测量帧和坐标帧是不同概念。所有数据都应同时检查字段布局、单位、时间基准、坐标系和有效性。文中的长度、缓冲上限、计数值属于教学示例；实际设备的电气参数、协议字段和数据手册要求必须按对应硬件核对。

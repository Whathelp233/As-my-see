# CUDA 与性能分析

本模块讲 GPU 并行计算如何接入应用数据流，怎样正确使用 CUDA stream、event 和异步传输，以及如何区分设备计算时间、端到端延迟与稳态吞吐。优化结论必须来自同一输入、同一测量口径和目标设备上的证据。

## 前置知识

- 能读基本的 C++ 或 Python，理解数组、指针、线程和浮点数。
- 熟悉 CPU 与 GPU、主存与设备内存的区别；不要求先会写复杂 CUDA kernel。
- 了解均值、中位数、百分位数和基本的误差来源。概率统计可复习[数学与信号基础](../数学与信号基础/README.md)。

## 阅读顺序

1. [CUDA 执行模型与数据通路](CUDA执行模型与数据通路.md)：从 CPU 循环、线程编号、内存布局到传输和 kernel 融合。
2. [CUDA 流、事件与异步流水线](CUDA流、事件与异步流水线.md)：理解 stream 顺序、event、pinned memory、缓冲区生命周期和真实重叠证据。
3. [性能测量、延迟与瓶颈分析](性能测量、延迟与瓶颈分析.md)：设计公平基准，解释延迟分位、吞吐、Amdahl 定律与 profiler 时间线。
4. [浮点精度与跨平台一致性](浮点精度与跨平台一致性.md)：理解 FMA、归约次序、边界判定和逐阶段差异定位。

# 计算机视觉与机器学习

本模块从像素级图像处理讲到语义分割模型、训练数据设计和部署数值一致性。它强调输入、标注、划分与推理的接口；架构名称本身不能替代数据和验证。

## 适用范围

- 颜色空间、阈值分割与形态学处理。
- U-Net 式编码器—解码器、细目标分割损失，以及 ResNet 编码器的取舍。
- 训练、开发与保留集的划分，标注语义，合成数据与真实数据的互补。
- 多模态预处理、模型导出、精度核对和训练—推理接口。

相机坐标、外参、图像与深度的几何配准由[坐标变换与传感器标定](../坐标变换与传感器标定/README.md)主讲；传感器时序、采集和通信见[传感器与硬件通信](../传感器与硬件通信/README.md)。网络延迟、GPU 占用和性能分析见[CUDA与性能分析](../CUDA与性能分析/README.md)；分割结果转成空间障碍与点云的处理见[点云处理与障碍检测](../点云处理与障碍检测/README.md)。本文不重复这些模块的推导。

## 前置知识

建议熟悉矩阵与张量、概率、梯度下降和图像坐标。U-Net 部分用到卷积、反向传播和 sigmoid；数据评测部分用到准确率、精确率、召回率与置信区间。

## 阅读顺序

1. [图像分割与形态学处理](图像分割与形态学处理.md)：从通道和阈值开始，理解二值掩膜如何经形态学运算改变形状。
2. [U-Net 与细目标分割](U-Net与细目标分割.md)：从逐像素 logits 推导到卷积、跳跃连接和类别不平衡损失。
3. [ResNet 编码器与分割架构选择](ResNet编码器与分割架构选择.md)：理解残差骨干、预训练与多模态输入适配，并建立公平的架构对照。
4. [训练数据划分与评测](训练数据划分与评测.md)：防止相邻帧泄漏，明确正例、负例、忽略区和保留集的职责。
5. [合成数据与训练推理一致性](合成数据与训练推理一致性.md)：把样本生成、模态缺失、导出、数值核对串成一条可复现管线。

## 常见数据管道

- 传统分割：彩色图像 → 颜色空间变换 → 阈值掩膜 → 形态学清理 → 连通区域或轮廓。
- 模型训练：分组后的图像与像素标注 → 同步增强 → 训练样本或缓存 → 网络 logits → 损失与权重更新 → 冻结的模型版本。
- 模型推理：图像和辅助模态 → 对齐、归一化、缺失标记 → 网络 logits / 概率 → 阈值掩膜 → 下游几何解释。

三条管道的输出含义不同。二值掩膜不是三维测量；训练标签不是传感器有效性；模型概率也不自动表示经过校准的置信度。

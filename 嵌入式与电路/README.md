# 嵌入式与电路

本模块从半导体器件和电路分析讲到微控制器外设、单板计算机接口与 PCB 基础。重点是理解电压、电流、工作区、信号电平和外设时序如何共同决定系统行为；板卡型号、引脚复用和软件 API 则以具体芯片数据手册和版本文档为准。

## 前置知识

建议熟悉电压、电流、电阻、电容、基尔霍夫定律和二进制表示。尚不熟悉复数阻抗的读者可先读[数学与信号基础](../数学与信号基础/README.md)中关于正弦稳态与频率响应的内容。

## 建议阅读顺序

1. [电信号、半导体与 PN 结](电信号与PN结二极管.md)：载流子、结区、二极管伏安特性及小信号模型。
2. [BJT 放大与工作点分析](BJT放大与工作点分析.md)：三极管工作区、静态工作点、共射放大和交流等效。
3. [运算放大器、差分与反馈](运算放大器差分与反馈.md)：差模/共模、运放闭环和反馈条件。
4. [多级放大与频率响应](多级放大与频率响应.md)：级间耦合、带宽、谐振负载和功率级。
5. [数制与数字编码](数制与数字编码.md)：进制转换、BCD、格雷码和有符号数。
6. [微控制器与常用外设](微控制器与常用外设.md)：GPIO、定时器、PWM、UART、I²C、中断与 DMA。
7. [板卡接口与 PCB 实践](板卡接口与PCB实践.md)：单板计算机与 MCU 的接口、电平、GPIO 管理、供电和走线。

## 相邻主题

- [传感器与硬件通信](../传感器与硬件通信/README.md)主讲编码器、IMU、传感器数据和物理通信链路；本模块只介绍 MCU 外设如何产生或读取这些信号。
- [ROS 与软件架构](../ROS与软件架构/README.md)主讲节点、话题、接口契约与 ROS 运行结构；本模块只说明 ROS 主机与微控制器之间的桥接边界。
- [数学与信号基础](../数学与信号基础/README.md)主讲信号、频域与估计方法；本模块仅在电路分析中使用所需的基础公式。
- [机器人运动学与控制](../机器人运动学与控制/README.md)主讲执行机构控制与闭环控制设计；本模块覆盖驱动级电路、PWM 时序和电气边界。

## 使用边界

文中的电路关系式均注明了电路拓扑和近似条件。GPIO 电压、驱动能力、定时器时钟、复用引脚和库函数均依赖具体器件与版本；实际设计须核对芯片数据手册、参考手册、板卡原理图和外设规格，不要把示例值当作所有板卡的额定参数。

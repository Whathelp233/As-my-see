# Qt 与界面开发

本模块介绍 Qt Widgets 应用如何组织对象、信号槽、窗口与控件，怎样处理输入事件和绘制，以及如何读写文件、嵌入资源并把界面扩展为 rqt 插件。重点是可迁移的 Qt/C++ 知识；ROS 节点、执行器、通信和业务状态由 [ROS 与软件架构](../ROS与软件架构/README.md)主讲。

## 前置知识

- 能阅读基本 C++：类、继承、指针、作用域、函数和 lambda 表达式。
- 了解事件循环、线程与文件路径的基本含义。
- 如需开发 ROS 插件，先熟悉 ROS 包与节点接口；见[ROS 与软件架构](../ROS与软件架构/README.md)。

## 建议阅读顺序

1. [Qt 对象模型、信号槽与线程](Qt对象模型、信号槽与线程.md)：从事件循环和 QObject 生命周期，理解信号连接、lambda 捕获、线程亲和性与 GUI 更新边界。
2. [Qt Widgets 布局、窗口与控件](QtWidgets布局、窗口与控件.md)：组合布局、主窗口、对话框和常用输入/展示控件。
3. [Qt 事件、绘制与样式](Qt事件、绘制与样式.md)：事件分发、过滤器、鼠标键盘输入、自定义绘制与 QSS。
4. [Qt 资源与文件读写](Qt资源与文件读写.md)：使用 .qrc 打包静态资源，处理文件选择、编码、错误和安全写入。
5. [rqt 插件与 GUI 线程桥接](rqt插件与GUI线程桥接.md)：把 Qt 界面嵌入 rqt，并为异步回调建立线程安全的界面更新路径。

## Qt 5 与 Qt 6

Qt 的主版本会改变部分 API 与构建方式。文章优先使用跨版本稳定的概念；涉及版本差异的代码片段会单独标注。开发前应确认目标 Qt 和 ROS 发行版，并使用该版本的官方文档与示例。示例只说明接口关系，按目标 Qt 版本核对构建工具与类参考。

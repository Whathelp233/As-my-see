# 几何与视觉融合及验证方法

视觉、深度和激光各自观测不同属性：颜色描述外观，主动深度提供几何测量但会缺测，单目网络输出受训练数据和尺度约束的预测，激光则只在射线命中处提供距离。
融合应保留每种证据的来源、有效性和坐标，不把“多个通道有响应”直接当成独立确认。

## 先建立可比较的观测

把一幅图像和一帧点云叠在一起，不代表它们已对齐。至少要确认：

1. 两个传感器的内参、畸变模型、图像尺寸和像素中心约定。
2. 外参的方向，例如 $T_{color\leftarrow depth}$，以及平移单位。
3. 图像与点云的采样时间；传感器运动时，应按各自观测时刻使用动态 TF。
4. 点投影到图像后发生遮挡时的处理，通常同一像素保留最近的正深度。
5. 图像畸变、缩放和裁剪是否与标定参数同步更新。

深度点先转到彩色相机系并投影：

$$
\mathbf p_c=R_{c\leftarrow d}\mathbf p_d+\mathbf t_{c\leftarrow d},\qquad
u=f_x\frac{X_c}{Z_c}+c_x,\quad
v=f_y\frac{Y_c}{Z_c}+c_y.
$$

写入像素网格时，不能把无投影点解释为自由空间；它们可能在遮挡边缘、图像边界之外或本来就缺测。重采样也需记录其坐标约定，
尤其是普通双线性插值和 `align_corners=True` 对应不同的像素坐标映射。

## 把单目预测转成有限的几何证据

学习式单目深度可能输出米制深度，也可能输出相对深度或逆深度。即使画面看来像深度图，像素值也未必可直接和传感器米值比较。

- **度量深度输出**：若模型预测 $\hat z$ 与传感器深度 $z$ 存在尺度偏差，
  可在可信对应像素上估计稳健比例 $s=\operatorname{median}(z/\hat z)$，再用 $s\hat z$。这只修正尺度，
  无法消除非线性偏差。
- **相对逆深度输出**：一种可检验的对齐模型是 $1/z\approx a\hat d+b$，其中 $a,b$ 由有效对应像素稳健拟合；
  之后仅对正且有限的结果求逆。该模型不保证适用于所有网络输出。

把预测深度通过相机内参反投影到三维后，变换到传感器几何参考系，再计算相对地面平面的预测高度。可在可信地面区拟合平滑偏差面，例如：

$$
g(u,v)=c_0+c_1u+c_2v+c_3u^2+c_4uv+c_5v^2,
\qquad h'(u,v)=h(u,v)-g(u,v).
$$

拟合样本应来自有效、近似平坦的地面像素，并排除障碍候选周边，避免模型把目标本身吸收到基线。拟合需要足够空间分布和满秩设计矩阵；样本稀少、
退化或异常值过多时应标记“不可评分”。

## 对候选线段做局部几何复核

对细小目标，用整幅图的均值容易被地面变化支配。可以针对每条候选线段，比较线内去趋势高度和邻近环带高度的中位数：

$$
s_{line}=\operatorname{median}_{p\in C} h'(p)
-\operatorname{median}_{p\in R(C)}h'(p),
$$

其中 $C$ 是候选线段像素集，$R(C)$ 是排除其他候选后的周边地面环带。正的局部差值可支持“候选表面高于附近地面”，但不能单独证明其语义类别。

评分之前要设覆盖条件：候选和环带都必须含有限几何像素，且两者的有限像素比例都达到最低值，地面面片拟合也有效。任一侧为空或覆盖不足时，
结果应为“不可评分”并保留原候选（fail-open），而不是把缺失的几何预测当负证据。评分阈值需要在独立、预先声明的数据上确定；
缺少覆盖的样本比例同样要报告。

```text
for each visually proposed segment:
    if ground model is invalid:
        keep segment; status = NOT_SCORABLE
    elif (finite_count(segment) == 0
          or valid_fraction(segment) < min_coverage
          or finite_count(local_ring) == 0
          or valid_fraction(local_ring) < min_coverage):
        keep segment; status = NOT_SCORABLE
    else:
        score = median(height_detrended[segment])
                - median(height_detrended[local_ring])
        if score < threshold:
            veto segment
```

候选线像素应来自实际逐段判定的组件或可靠骨架分支。稠密线响应图可能被地砖纹理、阳光边缘或阴影连成一个巨大连通域；将整块直接当成线缆候选，
会让标签重叠比例失真。骨架化后可以在交叉点处拆成线段，但短碎片、相交目标和未连通组件需要单列统计。候选必须与最终输出中的组件 ID 保持可追踪关系，
才能核查“哪条证据删掉了哪些像素”。

只有对原本通过视觉链路的候选做复核，才是在检验“附加证据能否减少误报”。把被前级拒绝的候选重新放回，会变成另一条召回路径，需另作独立实验和风险评价。

## 融合不能消除传感器的物理盲区

- **主动红外**：投射器会形成散斑、条纹或饱和区域。细线滤波器在 RGB 上有效，并不保证能直接迁移到 IR。应使用相同算法比较不同原始通道，
  同时核验视场和时间配对。
- **无效深度**：暗色、反光或透明目标可能造成缺测，但地缝、强光、遮挡、无纹理和超量程也会缺测。缺测区域可用于生成候选，不能单独作为“凸起”的高度证据。
- **单目网络**：预测表面高度容易带有全局倾斜、尺度偏差和材质偏差。先用传感器有效地面拟合偏差，再比较局部线段与环带。
  本文讨论的单目复核分数尚未验证为独立安全几何依据。
- **物理面积**：像素连通域需按距离相关的地面像素尺度转成平方米；固定像素面积门在图像上下部代表不同的物理大小。
- **时间证据**：连续帧需要先对齐同一空间位置，才能解释持续性。多帧计数不等于独立多次确认；静态背景和移动目标的更新机制不同。

以同帧地面纹理分布作为“正常地面”并做异常检测有一种自污染风险：若目标或大面积无效区进入正常样本，参考分布会包含目标本身，
后续联合门会把真目标压掉或让整片异常区域通过。检查异常检测时，应评估正常样本的空间纯度，查看特征热图，并做目标遮罩/样本选择消融，而不是只调分数阈值。

## 从实验结果中区分实现正确与效果有效

一个严谨的离线验证流程可以按以下顺序组织：

1. **锁定问题和指标**：明确输入帧、标签口径、忽略区、候选定义、阈值选择规则和停止条件。
2. **先验证几何夹具**：合成平面、已知凸起、外参投影、距离缩放与插值往返，检查符号、单位和像素映射。
3. **做实现一致性对照**：不同语言或硬件在同一输入上比较逐组件分数、状态和掩膜。高相关说明实现接近，不说明预测能区分障碍。
4. **分开报告粒度**：候选组件的 TP/FP 数、像素召回、每帧 FP 面积、地图有害格和车辆级后果是不同指标，不能互相代替。
5. **按距离、材质、清晰度和设备分层**：同时报告样本量、帧级配对差和不确定区间；稀少层不下强结论。
6. **遵守数据拆分**：调阈值只用允许的训练/开发数据；留出集和最终测试集不用于反复试错。
   模型训练与数据拆分的细节见[机器学习模块](../计算机视觉与机器学习/训练数据划分与评测.md)。
7. **记录覆盖和失败模式**：报告无效输入、不可评分比例、被拒绝的真目标、是否新增误报，以及输入数据与部署数据的差异。

预注册后发现问题可以修正实验方法，但必须先声明新问题和新判定规则，再运行新一轮；不能在看完留出结果后改阈值仍称其为独立验证。静态代码审查、合成单测、
离线数据效果、实时性能和端到端导航分别提供不同证据。

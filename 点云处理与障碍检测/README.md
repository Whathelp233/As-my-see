# 点云处理与障碍检测

本模块从传感器采样时间和坐标系出发，介绍点云去畸变、滤波、栅格表达、地面几何、低矮障碍证据及多模态复核。重点是判断几何证据能说明什么、何时失效，
以及如何验证一条处理链。

## 前置知识

- 三维向量、矩阵乘法、刚体变换与概率基础。
- 传感器时间戳、相机模型和 TF 的语义。
- 点云消息中坐标、单位、点内时间及无效值的表示。

## 阅读顺序

1. [点云时空同步与地图表达](点云时空同步与地图表达.md)：时序、逐点运动补偿、过滤、二维投影和占据射线。
2. [地面几何与低矮障碍证据](地面几何与低矮障碍证据.md)：参考平面、高度残差、有界拟合、传感器噪声与物理尺寸门限。
3. [几何与视觉融合及验证方法](几何与视觉融合及验证方法.md)：多源证据、线段复核、失效开放策略和实验设计。
4. [点云结构搜索与 kd 树](点云结构搜索与kd树.md)：近邻搜索的空间划分、正确回溯与可运行实现。

# 坐标变换与传感器标定

本模块讲清楚机器人坐标系的含义、刚体姿态的表示、传感器之间的空间关系，以及怎样设计和验证一项标定。核心问题不是“如何调一个角度”，而是：数据属于哪个坐标系、变换朝哪个方向、观测能确定哪些自由度，以及误差怎样传到最终点位。

## 前置知识

- 熟悉向量、矩阵乘法、三角函数和基本概率统计。
- 会区分点、方向向量和坐标系；不熟悉矩阵或误差分析时，先读[线性代数与数值计算](../数学与信号基础/线性代数与数值计算.md)与[概率统计与稳健估计](../数学与信号基础/概率统计与稳健估计.md)。
- ROS 使用者应了解 `frame_id`、时间戳和 TF；一般测量的采样时刻、单位与噪声模型见[传感器测量与时间戳](../传感器与硬件通信/传感器测量与时间戳.md)。

## 阅读顺序

1. [坐标系、刚体变换与 TF](坐标系、刚体变换与TF.md)：明确变换方向，掌握 SO(3)、SE(3)、四元数、李代数和 TF 时间语义。
2. [相机成像与内参标定](相机成像与内参标定.md)：从针孔投影、镜头畸变到标定板数据和重投影检查。
3. [空间外参与手眼标定](空间外参与手眼标定.md)：建立传感器间的固定空间关系，理解 AX=XB、相机—IMU 联合标定与时间偏移。
4. [几何约束、可观性与验证](几何约束、可观性与验证.md)：用平面、重力、旋转轴和多站点观测构造约束，并用独立数据验证结果。

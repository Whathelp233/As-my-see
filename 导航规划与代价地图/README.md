# 导航规划与代价地图

本模块介绍环境证据如何经过分层 costmap 更新成为规划代价，随后由全局搜索器生成路径，并由局部控制器转成速度命令。重点包括静态/动态图层、障碍 marking 与 clearing、TTL/衰减/冻结策略、膨胀、网格和运动学规划、DWB/MPPI/RPP，以及 OMPL 采样算法。

本模块不主讲传感器如何做地面分割或障碍几何分类；这些观测方法见[点云处理与障碍检测](../点云处理与障碍检测/README.md)。坐标变换与 TF 见[坐标变换与传感器标定](../坐标变换与传感器标定/README.md)，搜索所需的数值与概率基础见[数学与信号基础](../数学与信号基础/README.md)，运动学模型、反馈控制和执行器限位见[机器人运动学与控制](../机器人运动学与控制/README.md)。

## 前置知识

- 知道二维栅格的分辨率、地图原点和坐标系含义。
- 熟悉图、节点、边、路径长度以及基本向量几何。
- 理解机器人有尺寸，路径点无碰撞不代表整条车体运动安全。
- 阅读 ROS 2/Nav2 参数时，应知道传感消息、TF 时间戳和插件配置会随发行版变化。

## 阅读顺序

1. [分层代价地图与障碍生命周期](分层代价地图与障碍生命周期.md)：内部格值、更新窗口、标记/清除、体素投影、证据寿命、膨胀与禁行区。
2. [全局路径搜索与运动学可行规划](全局路径搜索与运动学可行规划.md)：Dijkstra、A*、NavFn、Smac 2D/Hybrid-A*、Theta*、硬安全域及可运行示例。
3. [局部轨迹控制与速度约束](局部轨迹控制与速度约束.md)：DWB、MPPI、RPP、TEB 的轨迹预测、评分与速度调节边界。
4. [采样规划与 OMPL](采样规划与OMPL.md)：状态空间、状态/运动有效性、PRM、RRT、RRT-Connect 与 RRT*。

## 数据链

传感器或人工约束 → costmap 图层的证据更新 → 合成的可通行性与软代价 → 全局几何/运动学路径 → 局部轨迹与速度命令 → 底盘控制。每一段都需要一致的坐标系、时间基准、障碍语义与机器人 footprint；上游地图可信不代表下游自动满足运动学或安全约束。

## 版本说明

ROS 1 `move_base` 和 ROS 2 Nav2 共享分层代价地图、障碍射线与路径/局部控制等概念，但服务器组织、生命周期、参数树和插件名称不完全相同。正文以概念解释为主，Nav2 链接指向核验时的 Rolling 文档；落地配置应按正在使用的发行版文档复核，不能把示例数值当默认值或通用推荐值。

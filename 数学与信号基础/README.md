# 数学与信号基础

本模块讲解机器人算法常用的线性代数、概率统计、稳健估计、最小二乘优化，以及连续与离散信号、频域分析和数字滤波。这里的公式说明通用模型；实际坐标约定、传感器误差和控制约束应由对应模块定义。

## 前置知识

建议熟悉代数、三角函数、函数图像和基本微积分。暂时不熟悉矩阵也可以从第一篇开始；概率统计和信号系统两条阅读线可独立进行。

## 阅读顺序

1. [线性代数与数值计算](线性代数与数值计算.md)：向量、秩、条件数、SVD 与线性最小二乘。
2. [概率统计与稳健估计](概率统计与稳健估计.md)：方差、协方差、在线统计、MAD 与 RANSAC 预算。
3. [非线性最小二乘优化](非线性最小二乘优化.md)：残差、雅可比、Gauss–Newton、LM、信赖域与鲁棒损失。
4. [Schur 补与局部可观测性](Schur补与局部可观测性.md)：变量消元、边缘协方差、规范自由度与局部弱方向。
5. [信号与系统基础](信号与系统基础.md)：信号分类、系统性质、卷积和 BIBO 稳定性。
6. [常用信号与理想冲激](常用信号与理想冲激.md)：阶跃、斜坡、冲激、周期、能量与功率。
7. [频域分析与相关](频域分析与相关.md)：复指数、傅里叶变换、DFT/FFT、相关与边界处理。
8. [数字滤波与平滑](数字滤波与平滑.md)：滑动均值、指数平滑、中值滤波和变化率限制。
9. [数学建模工作流](数学建模工作流.md)：从问题定义、假设和求解到验证与结果表达。

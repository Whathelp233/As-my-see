# Linux 与软件开发

本模块把 Linux 操作、系统接口、C++ 资源管理、构建系统、Git 协作和故障定位串成一套可复用的开发方法。重点是理解工具背后的边界：地址不是物理位置，文件描述符不是指针，构建成功不等于运行环境正确，异步完成也不等于自动取消。

## 前置知识

建议先会读基础 C/C++、终端命令和简单的 YAML/CSV 文件。阅读内存文章时，知道二进制与十六进制即可；不要求会编写内核代码。

## 阅读顺序

1. [Linux 虚拟内存与 x86 地址转换](Linux虚拟内存与x86地址转换.md)：从虚拟地址、分页、页表与缓存理解地址如何落到硬件。
2. [Linux 命令行、Shell 与系统诊断](Linux命令行、Shell与系统诊断.md)：掌握命令组合、脚本变量、远程登录与按证据排障。
3. [POSIX 文件 I/O、设备控制与套接字](POSIX文件IO、设备控制与套接字.md)：理解文件描述符、部分读写、`ioctl` 与 TCP 套接字接口。
4. [C++ 值类别、句柄与资源所有权](C++值类别、句柄与资源所有权.md)：澄清 `std::move`、引用、RAII、回调和容器的常见误区。
5. [CMake 构建、依赖与安装](CMake构建、依赖与安装.md)：用目标和依赖图组织项目，区分配置、编译、链接与安装。
6. [Git 协作与代码质量](Git协作与代码质量.md)：从工作区、暂存区、分支、评审和验证建立可追溯的改动流程。

7. [程序算法与数值边界](程序算法与数值边界.md)：状态初值、整数平方根、随机分布与边界条件。

## 相邻模块

ROS 节点、接口和 executor 的总体结构见 [ROS 与软件架构](../ROS与软件架构/README.md)。单消费者任务队列、异步结果所有权、取消与关闭顺序，以及日志队列背压，主讲于[软件模块与异步任务](../ROS与软件架构/软件模块与异步任务.md)；本模块只说明 C++/Linux 的底层接口，不重复这些并发设计。

## 使用边界

命令示例分为只读观察和会改变文件、配置、服务或远端状态的操作。需要变更时，先检查目标主机、路径、权限和回滚方式，再按该系统的当前官方文档执行。历史 Linux 内存章节主要讨论 IA-32（32 位 x86）教材模型；现代 x86-64 的地址宽度、页表层级和内核布局取决于处理器与内核配置，不能照搬历史常数。

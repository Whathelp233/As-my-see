# 程序算法与数值边界

算法正确性取决于状态定义、循环不变量和数值表示。小例子能帮助检查这些条件，但运行快慢必须在相同输入规模和实现条件下测量，不能由一次在线评测的排名推断。

## 动态规划：先定义第零个状态

每次上 1 或 2 级台阶，记 $a_n$ 为恰好到达第 n 级的方法数。按最后一步分类，两类方案互斥且覆盖全部方案，因此

$$
a_n=a_{n-1}+a_{n-2},\qquad a_0=1,\quad a_1=1.
$$

$a_0=1$ 表示什么也不做的空方案；由递推得到 $a_2=2$。若数组下标表示“第 n 级”，就不能把前两个元素初始化为 1、2。若下标从第 1 级开始，则需要明确另一套索引约定。

每个状态只依赖前两个状态，可将整张表缩为两个变量。下面是可独立运行的 Python 示例中的第一部分；其余函数见下一节。

```python
def require_nonnegative_integer(value):
    if type(value) is not int or value < 0:
        raise ValueError("expected a non-negative integer")


def count_steps(n):
    require_nonnegative_integer(n)
    previous, current = 1, 1
    for _ in range(n):
        previous, current = current, previous + current
    return previous
```

循环 k 次后，两变量分别为 $a_k,a_{k+1}$。算法执行 $O(n)$ 次加法，仅保存两个整数；整数本身会随 n 增大，所以“常数空间”指整数对象数量，若按位计量则并非常数。固定宽度 C++ 整数还必须处理结果越界。

若用试探解 $a_n=r^n$，特征方程为 $r^2-r-1=0$，两根为 $\phi=(1+\sqrt5)/2$、$\psi=(1-\sqrt5)/2$。代入初始条件得到

$$
a_n=\frac{\phi^{n+1}-\psi^{n+1}}{\sqrt5}.
$$

这是精确实数公式；直接用有限精度浮点数求幂再取整，大 n 时未必得到精确整数。需要整数结果时，整数递推或整数矩阵快速幂更合适。

## 整数平方根：用不等式定义答案

对非负整数 x，整数平方根是唯一满足

$$
r^2\le x<(r+1)^2
$$

的非负整数 r。逐个尝试直到平方超过 x，需要 $O(\sqrt{x})$ 次尝试。二分搜索可以利用单调谓词 $m^2\le x$，将尝试次数降到 $O(\log(x+1))$。

设 `left` 始终满足 `left**2 <= x`，`right` 始终满足 `right**2 > x`。取 `left=0, right=x+1` 建立初始不变量；每次更新一个端点，直至相邻。

```python
def integer_sqrt(x):
    require_nonnegative_integer(x)
    left, right = 0, x + 1
    while right - left > 1:
        middle = left + (right - left) // 2
        if middle <= x // middle:
            left = middle
        else:
            right = middle
    return left
```

循环执行时 `middle >= 1`，所以除法不会除以零。用 `middle <= x // middle` 等价于比较平方，但避免固定宽度整数的乘法溢出。Python 整数可扩展，移植到 C++ 时还要处理 `x+1` 在最大值处溢出的问题，例如采用足够宽的边界类型或另一套包含端点的不变量。中点写成 `left + (right-left)/2` 可避免两端直接相加溢出；向下或向上取整都可以设计正确算法，关键是更新规则保证区间严格缩小。

### 牛顿迭代与终止规则

对 $f(y)=y^2-x$，实数牛顿步骤是

$$
y_{k+1}=\frac12\left(y_k+\frac{x}{y_k}\right).
$$

正初值和停止误差需要明确；固定执行 15 次不能对任意输入保证精度。对于整数答案，可以从不小于真平方根的整数开始，采用向下取整的迭代：

```python
def integer_sqrt_newton(x):
    require_nonnegative_integer(x)
    if x < 2:
        return x
    estimate = x
    while True:
        candidate = (estimate + x // estimate) // 2
        if candidate >= estimate:
            return estimate
        estimate = candidate
```

从上界出发，严格下降的整数序列不会无限继续；最终返回 $\lfloor\sqrt{x}\rfloor$。某些非平方数会在两个邻近整数间振荡，所以这里在不再下降时结束。大整数的运算成本取决于位数；不能只按迭代次数比较该方法和二分法。

`exp(0.5*log(x))` 需要处理 x=0，还会引入浮点误差；转换为整数后可能落在边界两侧。需要精确整数答案时，使用整数算法或标准库整数平方根，比依赖一次浮点取整可靠。Python 的 `math.isqrt` 就定义为精确的向下取整整数平方根。

## 随机采样：分布和状态是两件事

伪随机数发生器用内部状态生成序列；固定算法、初始状态和调用顺序可用于重复实验。种子使用当前时间并不保证不同运行一定得到不同序列，同一时间粒度内初始化还可能重复。测试时通常显式记录固定种子，避免每次调用都重新播种。

对均匀整数 u 做 `u % m` 只有在发生器可取值的数量能被 m 整除时才保持完全均匀。例如 u 均匀取 0 到 7，模 3 的结果中 0、1 各出现 3 次，2 只出现 2 次。C++ 的 `rand()` 上界由 `RAND_MAX` 表示，不能把某个实现的上界 32767 当成通用常量。C++ 提供随机引擎与 `std::uniform_int_distribution` 分离的接口，由分布负责生成闭区间内均匀整数；这与直接取模的映射不同。

若“连续失败达到阈值后强制成功”，就不再是每次固定概率、相互独立的伯努利试验。应把连续失败次数作为显式状态，定义阈值是在本次抽样前还是后检查、成功何时清零，再分别测试边界。含状态的抽样系统不能用单次基础概率直接解释长期成功率。

窗口或图形库的 `initgraph` 等函数属于具体库接口，`graphics.h` 并非 C++ 标准头文件；选择界面技术时应按目标平台和工具链核对。Qt 对象与窗口机制见[Qt Widgets 布局、窗口与控件](../Qt与界面开发/QtWidgets布局、窗口与控件.md)。

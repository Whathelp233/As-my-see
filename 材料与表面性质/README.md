# 材料与表面性质

本模块把地面材料的组成、卷材/片材/条板等形态、表面纹理与光学状态分开讨论，并说明这些因素怎样影响图像与深度观测。重点是建立可重复的材料描述和成像验证方法；外观或算法结果不用于推断防滑、防火等产品性能。

## 前置知识

- 能区分材料、产品形态、表面处理和安装接缝。
- 了解图像像素、相机视场，以及深度图中“无效值”和“测得距离”的区别。
- 不熟悉成像几何时，可先读[相机成像与内参标定](../坐标变换与传感器标定/相机成像与内参标定.md)。

## 阅读顺序

1. [材料形态、表面结构与样本设计](材料形态、表面结构与样本设计.md)：区分材料家族、产品形态、表面纹理和铺设状态，并从视场与布局推导测试样本尺寸。
2. [表面光泽、主动成像与算法验证](表面光泽、主动成像与算法验证.md)：理解镜面反射、立体匹配与主动投光的边界，规划材料条件下的深度和检测验证。

## 相邻主题

- 相机坐标、视场和传感器间几何关系由[坐标变换与传感器标定](../坐标变换与传感器标定/README.md)主讲。
- 深度观测转成地面与障碍证据由[点云处理与障碍检测](../点云处理与障碍检测/README.md)主讲；本模块只说明表面条件怎样改变输入观测。
- 数据划分、指标和保留集由[计算机视觉与机器学习](../计算机视觉与机器学习/README.md)主讲；材质测试应按样本面板或采集批次划分，避免把相邻帧当作独立样本。
- 采集时间、传感器状态与数据有效性见[传感器与硬件通信](../传感器与硬件通信/README.md)。

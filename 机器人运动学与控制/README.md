# 机器人运动学与控制

本模块从几何关系走到可执行控制命令：建立运动学模型，推导刚体动力学，设计反馈与优化控制器，再把控制器接入硬件抽象层并用安全实验验证。正文以轮式移动底盘和关节执行器为例，保留可迁移的推导与工程方法，不依赖特定机器人项目。

## 阅读顺序

1. [机器人运动学与移动底盘](机器人运动学与移动底盘.md)：坐标约定、机械臂正逆运动学、雅可比，以及全向轮、麦克纳姆轮和舵轮底盘。
2. [拉格朗日动力学建模](拉格朗日动力学建模.md)：广义坐标、约束、能量法、摆与机械臂方程，以及符号推导工作流。
3. [PID、轨迹与线性最优控制](PID、轨迹与线性最优控制.md)：离散 PID、抗积分饱和、串级环、前馈、速度曲线与 LQR。
4. [MPC 与全身控制](MPC与全身控制.md)：有限时域最优控制、滚动优化、约束、多任务优先级与全身逆动力学。
5. [ROS 控制器与实时数据流](ROS控制器与实时数据流.md)：ROS 1 ros_control 与 ROS 2 ros2_control 的硬件、控制器、接口和生命周期。
6. [控制器辨识、调试与安全验证](控制器辨识、调试与安全验证.md)：控制器标定、测量设计、故障定位、命令失联保护与分阶段验证。

## 前置知识与边界

阅读前建议掌握线性代数、微积分、常微分方程、经典力学与基础 C++。矩阵最小二乘、滤波、坐标变换与 TF 的主讲内容分别见[数学与信号基础](../数学与信号基础/README.md)和[坐标变换与传感器标定](../坐标变换与传感器标定/README.md)；ROS 节点与通信机制见[ROS 与软件架构](../ROS与软件架构/README.md)，驱动与编码器/IMU 通信见[传感器与硬件通信](../传感器与硬件通信/README.md)。本模块只在控制所需处使用这些概念。

式子中的车体坐标、轮序、正方向和角度原点都会影响符号。文章会在第一次使用时写明约定；具体机械结构应先用低风险试验验证电机和编码器方向。ROS、控制器和数学库的 API 会随发行版变化，代码片段只说明接口思路，落地时应查当前发行版文档。

## 贯穿各章的控制链

期望轨迹或操作命令 → 控制律与逆运动学 → 执行器参考值 → 驱动器与机械系统 → 编码器/惯性传感器反馈 → 状态估计与误差计算。任一环节都必须有明确单位、时间戳、坐标系和饱和/故障策略。

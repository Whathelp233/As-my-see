# 控制器辨识、调试与安全验证

调试的目标不是让某次动作“看起来能动”，而是用可重复的输入和有时间戳的观测，判断模型、方向、延迟、饱和和增益是否满足预先定义的标准。每次只改变一个主要因素，保留原始测量和测试条件。

## 1. 先验证信号链，再调增益

在给机构闭环命令前，沿整条链逐项确认：

1. 参考量、反馈量、控制量的名称、单位、符号、坐标系和采样周期；
2. 编码器零点、正方向、减速比和角度展开方式；
3. 驱动器工作模式、限幅、使能状态和故障码；
4. 参考消息是否新鲜，硬件读数和控制命令的时间戳是否可比较；
5. 执行器的硬件限位、急停和软件安全状态是否有效。

首先在低风险、低幅值下发一个短小的正向命令，确认测量值沿期望方向变化。若方向相反，应修正坐标变换、编码器极性或电机接线定义，不能靠随意翻转某一级 PID 符号掩盖问题。检查零速漂移、量纲换算和饱和标志后，才进入增益调试。

## 2. 设计可诊断的测量

一次最小控制日志建议包含：

| 信号 | 用途 |
|---|---|
| 单调时钟时间戳与实际周期 $T_s$ | 检查调度抖动、消息新鲜度和端到端延迟 |
| 期望位置/速度/姿态 | 确认控制器输入和测试激励 |
| 原始测量与滤波后测量 | 区分传感器噪声、滤波延迟与控制误差 |
| 误差、积分状态、微分状态 | 找出积分饱和、重置和噪声放大 |
| 未限幅控制量、限幅后控制量 | 判断是否被输出饱和或安全限幅截断 |
| 驱动器回读、限位/故障状态 | 区分软件命令与实际执行情况 |
| 温度、电流、母线电压等可用状态 | 检查负载、能量供应和热保护影响 |

记录单位、控制模式、测试载荷、环境、软件/参数版本和人为操作。若消息发布端与采集端时钟不同步，不能直接用时间戳相减得出毫秒级延迟；应使用同一时钟源或先测量时钟偏差。

## 3. 用阶跃和重复试验观察闭环

安全条件允许时，使用小幅阶跃或斜坡作为输入，观测从命令变化到反馈稳定的响应。常见指标包括：

- **死区/响应延迟**：命令变化后输出开始明显变化前的时间；
- **上升时间**：输出从初始值到达目标一定比例所用时间；
- **超调量**：最大偏离目标的幅度或相对比例；
- **调节时间**：进入并保持在目标误差带内所需时间；
- **稳态误差**：稳定阶段参考与测量差；
- **重复性**：相同输入多次测试的误差分布、标准差和最坏值。

测试激励必须处在行程、速度、加速度、转矩和电流限制内，不能为追求明显响应而逐渐加大到失控。需要比较的测试要保持载荷、供电、安装、滤波、采样和参数一致，并报告多次试验；只报告最好的一次会掩盖抖动、温漂和偶发失效。

## 4. 稳健的 PID 调试顺序

1. 检查单位与符号，先确认执行器与传感器方向。
2. 使用很小的安全目标，关闭或置零积分、微分与模型前馈，建立比例控制基线。
3. 增大比例增益，观察响应速度、振荡和饱和；若发生持续振荡或限幅，退回稳定范围。
4. 在测量信号噪声允许时加入微分阻尼，并按采样率调整微分低通。不能把微分噪声当成系统震荡而盲目加大增益。
5. 只有稳态偏差确需积分修正时才增加积分，并配置积分限幅、条件积分或反算抗饱和。
6. 逐级闭合串级环：先调稳定内环，再调外环；最后小幅加入速度/加速度/重力前馈。
7. 在不同负载、方向、速度和工作区间重复验证，检查控制量饱和、限位和失联后的恢复。

不同摩擦、弹性、传动比和驱动器电流环会产生不同响应。比例增益上调、积分消偏、微分加阻尼只是可检验的起点，不是对所有系统都成立的固定配方。

## 5. 执行机构校准与限位验证

找零、限制角度或检测机构端点时，先制定小速度、短时间、有限力矩的试验方案。确认机械端点不会夹伤人员或破坏零件；使用独立限位开关/驱动保护时，检查其实际接线和失效状态。

对需要回零的关节，可用“慢速靠近参考标记 → 触发后退出 → 更慢地同向接近 → 读取重复零位 → 设置偏置”的状态机。设计时规定触发窗口、最大运行时间、方向、退出距离、零位容差及故障时动作。若两次回零差异超出容差，不得静默选取一个偏置继续运行。

对有限角度的机构，限位值应来自可靠的机械测量，并保留足够制动距离；在低速下分别验证正、负方向的软限位、硬件限位和故障路径。机械限位不等于所有姿态都安全，线缆缠绕、负载干涉和接触力还需要单独判断。

## 6. 电动与气动执行机构接口

执行器接口决定控制器能直接控制什么。电机驱动器可能接收电流、力矩、转速、位置或电压命令；这些命令不是同一种物理量。气动缸常由方向阀切换伸出、缩回或保持状态，只有带比例阀、位置/压力反馈和相应模型时，才能把电信号按连续位置或力来闭环调节。

理想气缸的静态推力近似为
$$
F\approx pA,
$$
其中 $p$ 是有效压差、$A$ 是活塞有效面积。实际推力还受密封摩擦、供气压降、流量、负载和机构力臂影响。气缸两端的磁性开关只能说明活塞到达检测区域，不能直接给出连续位置或接触力。不同阀在断电时可能保压、排气或弹簧复位；不能默认某个电信号状态一定是机械安全状态，应结合阀结构、储能释放路径和硬件保护定义故障动作。

对于采用离散阀控的机构，可将使能、伸出、缩回、到位、超时、压力不足和故障建成显式状态机，并验证不允许的相反阀命令不会同时打开。状态机逻辑、传感器反馈和测试流程与电动执行机构相同，但输入输出约束需按气动特性重新建模。

## 7. 电机/底盘能力与功率模型

转矩 $\tau$ 与角速度 $\omega$ 的乘积是轴端机械功率：
$$
P_\mathrm{mech}=\tau\omega.
$$
这说明相同机械功率下，转矩和转速存在权衡；它不意味着真实电机在整个速度范围内都保持恒功率。电机的可用转矩受电流/温度和驱动器限制，最高转速受反电势、母线电压与机械负载限制，减速器和轮地接触还会再限制输出。

若需要根据电池/驱动能力限制底盘速度或加速度，应从实际可测信号建立模型：记录目标速度、轮速、电流/电压、供电状态和负载，在多个安全运动条件下拟合，再在未参与拟合的速度/方向/负载组合上验证。只用单一轨迹拟合到的经验公式不能外推成通用功率定律。对同一数据不断调整参数并报告拟合效果，会产生过拟合；应事先约定指标并留出独立验证条件。

## 8. 逐级验证和失效处置

按风险由低到高分层验证：

1. **静态检查**：尺寸/惯量/单位、控制器配置、关节接口、范围校验和异常状态处理。
2. **离线/仿真**：用已记录数据或模拟硬件走完整控制链；确认轨迹、状态机与超时处理，不向真实电机下发命令。
3. **受约束台架**：固定机构并隔离运动范围，使用限流/低速/小行程命令，确认急停和物理限位可触发。
4. **低风险整体运行**：在清空的测试区内逐步增加速度和负载，先短距离/短时，再扩展条件；每步都检查温升、饱和和软件错误。
5. **独立复测**：换人员或重新启动后重复关键检查，确认测试不是依赖偶然的残留状态或手工操作。

若反馈失联、周期超时、命令非有限数、驱动过流/过温或状态机不一致，应立即停止新的运动命令，保持设备进入预定义安全状态，并保存诊断快照。软件错误恢复要经过故障确认与重新使能流程；不能自动清故障后立刻恢复上一目标。

自动评测时，应预先冻结测试输入、阈值、成功规则和失败处置。把测试数据分为调参集与独立验证集；只在调参集上表现良好，不代表对新载荷或新环境也可靠。

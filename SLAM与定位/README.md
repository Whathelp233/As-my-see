# SLAM 与定位

本模块介绍机器人如何用带噪声的运动与环境观测同时估计轨迹和地图，并以 Cartographer 2D 为例梳理局部建图、位姿图、回环和纯定位。扫描匹配与点云配准是本模块的主讲主题，涵盖 ICP、GICP 与 NDT 的目标、求解和退化边界。

## 前置知识

- 向量、矩阵、概率、最小二乘和基本数值优化。
- 刚体变换、坐标系、时间戳及传感器外参；可先读[坐标变换与传感器标定](../坐标变换与传感器标定/README.md)。
- 激光点云的采样、滤波和邻域搜索；可先读[点云处理与障碍检测](../点云处理与障碍检测/README.md)。

## 阅读顺序

1. [SLAM 建模与 Cartographer 局部建图](SLAM建模与Cartographer局部建图.md)：建立状态估计视角，沿着测距数据、去畸变、前端匹配和重叠子图理解 Local SLAM。
2. [扫描匹配与点云配准](扫描匹配与点云配准.md)：由已知对应的 Kabsch/SVD 推到 ICP、点到面、GICP 与 NDT，并分析初值、可观性和收敛边界。
3. [Cartographer 位姿图、回环与定位](Cartographer位姿图、回环与定位.md)：理解节点与子图约束、分支定界搜索、稀疏位姿优化、规范自由度、纯定位和地图状态。

## 相邻模块

- [数学与信号基础](../数学与信号基础/README.md)：最小二乘、非线性优化、鲁棒估计、滤波、Schur 补与局部可观测性；本模块说明这些工具怎样组成 SLAM 前后端。
- [坐标变换与传感器标定](../坐标变换与传感器标定/README.md)：SE(3)、外参、TF 与几何约束；Kabsch 和完整点云配准流程由本文模块的[扫描匹配与点云配准](扫描匹配与点云配准.md)主讲。
- [传感器与硬件通信](../传感器与硬件通信/README.md)：编码器、IMU、采样时间和消息数据流；本模块讨论这些测量进入状态估计后的作用。
- [点云处理与障碍检测](../点云处理与障碍检测/README.md)：点云时空处理、地图表达和障碍证据；本模块聚焦扫描到子图的匹配及轨迹估计。
- [导航规划与代价地图](../导航规划与代价地图/README.md)：导航地图的代价、障碍生命周期和路径规划；SLAM 的概率占据图不是代价地图。

## 阅读边界

文中的数值只在明确标成“教学示例”时用于演算。Cartographer 的配置、2D/3D 路径和版本行为可能不同；理解算法时应把观测模型、参数化和具体实现区分开。

# Cartographer 位姿图、回环与定位

Local SLAM 负责连续跟踪和局部子图；Global SLAM 则试图把分散的局部结果放进一致的全局坐标系。它的核心是位姿图：节点和子图是变量，扫描匹配、局部插图关系和其它传感器测量形成约束边。回环是产生全局几何约束的一种来源，后端优化的对象是位姿，而不是把整张地图逐点变形。

## 节点、子图和约束

把节点 $j$ 的全局位姿记作 $X_j$，子图 $i$ 的全局位姿记作 $S_i$。扫描与子图匹配提供一个子图系下的节点相对位姿测量 $Z_{ij}$：

$$Z_{ij}\approx S_i^{-1}X_j.$$

约束残差可抽象写成：

$$r_{ij}=\operatorname{Log}\!\left(Z_{ij}^{-1}S_i^{-1}X_j\right).$$

`Log` 把相对刚体变换的误差映射到局部向量空间；具体参数化、左右扰动和残差尺度要与实现保持一致。常见边分两类：

- **子图内约束（intra-submap）**：节点在局部建图时已经插入该子图，边连接节点与其所属子图，维持短程结构。
- **跨子图约束（inter-submap）**：重新将节点扫描与其它已完成子图匹配后得到。它可以是同一条轨迹的回环，也可以是新旧轨迹之间的定位关联。

所有残差组成加权优化问题：

$$\min_{\{X_j\},\{S_i\}}\sum_{(i,j)}\rho\!\left(r_{ij}^T\Omega_{ij}r_{ij}\right).$$

其中 $\Omega_{ij}$ 表达测量置信度，$\rho$ 可减弱大残差边的影响。稀疏性来自每条边只连接少量位姿变量；线性化后可以使用稀疏最小二乘方法求解。有关雅可比、正规方程、Schur 补和鲁棒核的通用推导见[数学与信号基础](../数学与信号基础/README.md)。

## 候选搜索：Fast Correlative Scan Matcher

回环检测需要回答两件事：哪些旧子图值得尝试，以及扫描和子图能否在几何上对齐。Cartographer 2D 的 Fast Correlative Scan Matcher 在离散的平移和角度候选中搜索高分扫描到子图匹配；分支定界通过上界提前排除大块平移候选。

对角度已固定的扫描点格子索引 $k_i$，平移 $\delta$ 的分数可写成：

$$S(\delta)=\frac{1}{N}\sum_i P(k_i+\delta).$$

对宽度为 $w$ 个格子的平移块，预计算每个点可能覆盖窗口中的最大格子概率：

$$M_w(k)=\max_{0\le a,b<w}P(k+(a,b)),$$

于是该平移块内任一位移的分数不超过：

$$U_w(\delta)=\frac{1}{N}\sum_iM_w(k_i+\delta).$$

若候选上界已经低于当前最好分数或接受门限，就可以剪去它及其后续子块；否则把平移块分成更小块，直到评估单个离散位移。这里角度通常另行离散枚举，树结构主要细化平移。

分支定界在给定离散候选、评分和搜索范围内剪枝，不代表对连续位姿或任意全局位置找到数学上的全局最优。搜索范围外的正确解仍不可见；走廊和重复结构会让分数上界变松，并可能产生多个高分候选。Cartographer 论文介绍了 2D 扫描到子图约束的实时分支定界方法；[算法流程说明](https://github.com/cartographer-project/cartographer_ros/blob/master/docs/source/algo_walkthrough.rst)也区分候选 Fast Matcher 与后续精修。

常见后端匹配顺序是先快速离散搜索，再用连续扫描匹配器在高分候选附近精修，最后按分数门限决定是否接受约束。局部搜索依赖现有相对位姿初值；对整张子图范围进行搜索可以扩大候选范围，却需要更多计算。分数门限、匹配策略和输入滤波应一起评估，调低门限会增加约束数量，也会引入错误回环风险。

## 位姿图优化与规范自由度

只使用相对位姿约束时，把整张图中的所有位姿同时左乘同一个全局刚体变换，不会改变边之间的相对关系。因此，图的绝对原点和朝向并未由这些测量决定。这种自由度称为 gauge freedom（规范自由度）。求解时必须通过固定一个锚点、加入先验或采用等价约束来选定坐标系，否则线性化系统会秩亏。

2D 位姿图变量常为 $(x,y,\theta)$，每条相对约束比较预测的节点-子图变换和测量变换；3D 则在 $SE(3)$ 上处理平移和旋转。一次线性化可写为：

$$J\,\Delta x\approx-r,\qquad (J^TWJ)\Delta x=-J^TWr.$$

稀疏求解能利用图连接结构。大闭环残差可用 Huber 等鲁棒损失降权，例如对 $s=\|r\|^2$：

$$\rho_\delta(s)=\begin{cases}s,&s\le\delta^2,\\2\delta\sqrt{s}-\delta^2,&s>\delta^2.\end{cases}$$

大残差从二次惩罚转为对误差范数近似线性增长。鲁棒核降低异常边的影响，但不会自动判定一条边语义上错误；高权重错误约束仍可能拖动图。权重作用于什么量、$\delta$ 的单位及是否对某类边使用鲁棒核，都必须查看具体实现。

优化可在后台执行，前端继续产出局部位姿和节点。新一轮优化写回时，既要更新已有节点与子图，也要保证优化期间新产生的节点能衔接到新的局部到全局变换。观测全局轨迹时应同时记录局部位姿、跨地图变换、匹配分数、约束数量和优化结果，不能只看全局地图图像。

## 纯定位与重定位

复用已有地图时，纯定位仍需要跟踪新数据。一个常见流程是：

1. 加载已有子图和图状态，并将地图轨迹固定，使优化不会改写它。
2. 创建新的传感器轨迹，持续运行局部估计并形成临时节点/子图。
3. 用已知初始位姿附近的局部搜索，或对旧子图进行更大范围的全局候选搜索。
4. 一旦建立跨轨迹约束，优化新轨迹的全局位置；继续扫描后再由局部测量和已知地图约束更新。
5. 用裁剪策略限制新定位轨迹保留的近期子图数量。

“固定旧地图”和“裁剪新轨迹历史”是两种不同机制：前者规定哪些变量可优化，后者控制新轨迹的临时地图规模。纯定位不是直接对一张静态 `OccupancyGrid` 做单帧最近邻，也不等同于 AMCL 粒子滤波；其全局位姿估计和数据关联来自当前位姿图约束与扫描匹配。

初始位姿明显错误、环境重复、传感器外参或时间戳不一致时，局部匹配可能一直对不上旧地图。开始轨迹或服务调用成功只说明建立了计算对象，不表示已经完成定位。可先检查旧地图是否固定加载、点云几何是否与建图时兼容、是否产生跨轨迹候选、分数是否越过门限、优化后位姿是否稳定。

## 状态保存与地图输出

Cartographer 序列化状态（常见扩展名为 `pbstream`）保存的是 SLAM 状态，而不是原始 ROS bag 或直接可显示的栅格图片。它通常包含恢复位姿图和子图所需的状态数据；具体序列化字段、旧版本兼容性和是否包含未完成子图取决于版本及保存选项。要逐帧复现传感器输入，应另外记录 bag。

ROS 适配层可发布子图列表，再由单独的占据栅格节点查询子图纹理并拼成 `OccupancyGrid`。后端优化改变子图全局位姿时，地图拼接会更新；输出栅格的采样分辨率不会创造子图中没有的几何细节。TF 如何把全局修正与连续局部里程计分配到 `map`、`odom` 和机器人 frame，应结合[坐标变换与传感器标定](../坐标变换与传感器标定/坐标系、刚体变换与TF.md)中的变换方向和系统唯一发布者规则检查。

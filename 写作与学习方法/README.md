# 写作与学习方法

## 范围

本模块介绍 Markdown 的常见结构、数学公式在不同渲染器中的边界、LaTeX 文档的组织与排版，以及把学习目标变成可检查练习的做法。这里的公式只用于展示语法。

## 前置知识

会编辑纯文本文件即可开始。阅读数学示例需要理解变量、上下标和分数；LaTeX 文章不要求已有排版经验。

## 阅读顺序

1. [Markdown 公式与折叠](Markdown公式与折叠.md)：先理解 Markdown、公式扩展、代码围栏和 HTML 折叠块。
2. [LaTeX 入门与排版](LaTeX入门与排版.md)：学习 TeX 文档的结构、文字、列表、图片及中文排版。
3. [LaTeX 数学、表格与引用](LaTeX数学、表格与引用.md)：练习公式、矩阵、表格、代码片段与交叉引用。
4. [学习计划与复盘](学习计划与复盘.md)：把知识拆成前置概念、练习、项目任务和反馈。

## 相邻模块

- 需要学习数学概念时，参阅[数学与信号基础](../数学与信号基础/README.md)；本模块只讲写出符号的方法。
- 个人观点、文化阅读与人际经验见[文化与个人思考](../文化与个人思考/README.md)。
- 文档协作、版本管理和软件工具见[Linux 与软件开发](../Linux与软件开发/README.md)。
- 学习嵌入式或电路知识时，可从[嵌入式与电路](../嵌入式与电路/README.md)的主题文章选取一个练习对象。

Markdown 扩展和 LaTeX 宏包会随平台、文档类及安装环境而不同；文章中的示例应在目标渲染器或编译环境中检查。

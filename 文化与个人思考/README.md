# 文化与个人思考

## 范围

本模块收录文化阅读、个人价值取向、职业判断和人际经验。读者应区分可以查对的经典文本与起卦规则、作者当时的观察，以及根据情境作出的推测。个人观点能提供自我检查的问题，但不能直接当作普遍规律；《易经》的占筮传统是历史文化实践，不是经科学验证的预测方法。

## 前置知识

无需专门背景。读《易经》一篇时，先理解阴爻、阳爻和卦从下往上的排列；其他文章可以独立阅读。

## 建议阅读顺序

1. [职场协作与人际判断](职场协作与人际判断.md)：把个人经验中的提醒整理成提问、承诺、反馈和关系判断的方法。
2. [学习选择与职业判断](学习选择与职业判断.md)：阅读关于基础学习、专业选择和行业风险的个人观点及其边界。
3. [《易经》的卦象与占筮传统](易经与象征性思考.md)：了解八卦、六爻、两种起卦方式和一种传统断卦规则。
